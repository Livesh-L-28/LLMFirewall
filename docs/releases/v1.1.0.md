# LLMFirewall Core v1.1.0 Release Notes

**Release Date**: October 5, 2026  
**PyPI Distribution**: `llmfirewall-core`  
**Python Import**: `llmfirewall`  
**Version**: `1.1.0`

---

## Highlights

LLMFirewall Core v1.1.0 is a major feature and performance upgrade expanding defense-in-depth across the entire AI security lifecycle. It introduces advanced prompt injection heuristics, in-memory L1/L2 scan caching with an **~8x speedup**, multi-turn session tracking with exponential decay, finding correlation and blast radius estimation, pure ASGI 3.0 middleware, streaming text guardrails, and enterprise SIEM observability.

v1.1.0 strictly maintains 100% backward compatibility with all v1.0.0 public APIs.

---

## Major Features

### 1. Advanced Prompt-Injection Defense 2.0 (Phase 45)
- **Multi-Vector Obfuscation Normalization**: Detects and neutralizes Unicode homoglyphs, zero-width characters, bidirectional (BiDi) overrides, and leetspeak substitution.
- **Structural Intent Analysis**: Intercepts role confusion attempts, indirect prompt injections hidden within markdown/XML delimiters, and assistant impersonations.
- **Context & Source Tracking**: Differentiates between system prompt instructions and untrusted third-party RAG or web sources via `PromptSecurityContext`.

### 2. High-Performance L1/L2 Scan Caching (Phase 52)
- **`ScanCache`**: Thread-safe bounded LRU in-memory cache with configurable TTL and deterministic SHA-256 keys binding prompt text, evaluation direction, and security policies.
- **Context Isolation**: Ephemeral session IDs, timestamps, and request nonces are automatically filtered out of cache keys to prevent cache fragmentation.
- **Empirical 8.1x Speedup**: Reduces P50 scan latency from `0.309 ms` (cold) to `0.038 ms` (`38 microseconds`) on warm hits with a 99.9% hit ratio.
- **`RegexCache`**: Pre-compiles and caches complex regular expressions across detectors.

### 3. Risk Intelligence 2.0 & Attack Chains (Phase 50)
- **`SessionRiskTracker`**: Multi-turn risk accumulator with continuous exponential temporal decay, detecting low-and-slow probing attacks over time.
- **`FindingCorrelationEngine`**: Correlates atomic findings across detectors to identify compound multi-stage attacks (`EXFILTRATION_CHAIN`, `REMOTE_EXECUTION_CHAIN`, `INDIRECT_RAG_POISONING`, `PRIVILEGE_ESCALATION`, `MULTI_VECTOR_FLOOD`).
- **`BlastRadiusEstimator`**: Quantifies downstream blast radius, identifying reachable services, exposed data classifications, and prescribing immediate containment actions.

### 4. Developer Integrations 2.0 (Phase 51)
- **`LLMFirewallASGIMiddleware`**: Pure ASGI 3.0 middleware with zero external dependencies (no FastAPI or Starlette required), inspecting streaming HTTP bodies and WebSockets.
- **`StreamingTextGuard`**: Boundary-aware sliding window guard scanning continuous LLM token streams.
- **Unified Clients**: `LLMFirewallClient` and `AsyncLLMFirewallClient` offering clean, ergonomic APIs for synchronous and asynchronous LLM pipelines.
- **Convenience Entrypoints**: Direct `firewall.scan_prompt()` and `firewall.scan_output()` methods.

### 5. Policy-as-Code 2.0 & Static Linter (Phase 49)
- **`PolicyLinter`**: Static policy validation engine detecting shadowed unreachable rules, logical contradictions, rule evaluation cycles, and invalid regular expressions.
- **Compound Predicates**: Advanced rule conditions (`min_confidence`, `category`, `direction`) with explicit logical operators (`and`, `or`).

### 6. Observability & Enterprise SIEM Integration (Phase 54)
- **`SecurityDashboardAPI`**: Programmatic endpoints providing aggregate posture metrics, time-bucketed timeseries, and sanitized paginated events.
- **Common Event Format (CEF) SIEM Exporter**: Seamless streaming export to Splunk, ArcSight, IBM QRadar, and Microsoft Sentinel.
- **Prometheus Cache Telemetry**: Real-time counters for cache hits, misses, and hit ratio.

### 7. Adversarial Evaluation Engine (Phase 53)
- **`AdversarialMutationEngine`**: Generates automated adversarial attack variants (Unicode homoglyphs, invisible chars, role confusion, RAG poisoning, tool injection).
- **`AdversarialRedTeamRunner`**: Clusters failure patterns into `FailureCluster` reports and computes bypass percentages.


## Migration & Compatibility Notes

- **Zero Breaking Changes**: All v1.0.0 public APIs, classes, and configurations remain 100% supported and fully functional.
- **Automatic Caching**: In-memory `ScanCache` is enabled by default with a safe 5,000-entry capacity and 1,800s TTL. To disable: `FirewallConfig(cache=ScanCacheConfig(enabled=False))`.
- **Pure ASGI Available**: If you previously used `FirewallMiddleware` from `llmfirewall.integrations.fastapi`, you can now also use `LLMFirewallASGIMiddleware` from `llmfirewall.integrations` for zero-dependency ASGI servers.
