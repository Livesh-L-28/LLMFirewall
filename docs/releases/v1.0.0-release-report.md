## Known Limitations
- Heuristic and regex detection is optimized for known injection signatures and patterns; highly novel adversarial evasions require layered defenses.
- Built-in prompt injection and PII patterns are designed primarily for English-language text.
- LLMFirewall operates at the application layer and must be deployed alongside identity/IAM management, network WAFs, and API gateways.
